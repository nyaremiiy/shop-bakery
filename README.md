# Shop Bakery

Лендинг мережі сучасних пекарень: адаптивна верстка без фреймворків і залежностей, з упором на швидкодію та доступність.

## Стек

- Семантичний HTML5, нативні `<dialog>` для модалки та мобільного меню
- Сучасний CSS: custom properties, `clamp()`, grid, `:has()`, scroll-snap, `prefers-reduced-motion`
- Vanilla JS (ES-модуль, ~5 КБ): IntersectionObserver, ResizeObserver, нативна валідація форм

## Швидкодія

- Усі зображення в WebP і зменшені до реально потрібних розмірів (було ~2,1 МБ, стало ~0,3 МБ)
- Адаптивне hero-зображення (`srcset`) з `preload` і `fetchpriority="high"`
- Self-hosted змінні шрифти з окремими кириличним і латинським сабсетами (`unicode-range`), preload головних файлів
- Swiper замінено нативною scroll-snap каруселлю, тож зовнішніх скриптів і стилів більше немає
- Google Maps підвантажується лише тоді, коли користувач доходить до секції контактів
- `width`/`height` на всіх зображеннях задля нульового CLS, `loading="lazy"` для всього нижче першого екрана

## Запуск

Збірка не потрібна. Досить запустити будь-який статичний сервер:

```bash
npx serve .
# або
python3 -m http.server
```
